헬스 루틴 & 세트 기록 — PWA 패키지

포함 파일
- index.html: 기존 앱을 PWA 메타데이터와 서비스 워커 등록 코드로 보강한 파일
- manifest.json: 앱 이름, 아이콘, 설치 표시 방식
- service-worker.js: 앱 파일과 외부 리소스 캐시
- icons/: 192px / 512px 앱 아이콘

설치 방법 (안드로이드 Chrome)
1. 이 폴더의 파일을 모두 HTTPS를 지원하는 웹 호스팅에 업로드합니다.
   예: GitHub Pages, Netlify 등
2. 업로드한 사이트 주소를 안드로이드 Chrome에서 엽니다.
3. Chrome 메뉴(⋮)에서 '앱 설치' 또는 '홈 화면에 추가'를 선택합니다.
4. 처음에는 온라인 상태에서 앱을 한 번 열어 리소스를 캐시합니다.

중요한 참고 사항
- 보안상 PWA 설치는 일반적으로 HTTPS 주소가 필요합니다. 컴퓨터의 localhost는 개발용 예외입니다.
- 기존 HTML은 Tailwind CSS를 CDN에서 불러옵니다. 서비스 워커가 첫 온라인 실행 후 이를 캐시하도록 구성했지만,
  CDN이 처음부터 차단되어 있거나 첫 실행 때 네트워크 오류가 있으면 스타일이 적용되지 않을 수 있습니다.
  완전한 오프라인 독립성을 원하면 Tailwind CSS를 로컬 파일로 포함하는 후속 개선이 필요합니다.
- 기존 앱의 데이터는 브라우저 localStorage에 저장됩니다. 브라우저 데이터 삭제 또는 앱/사이트 데이터 초기화 시
  기록이 사라질 수 있으므로 앱 안의 백업 기능을 정기적으로 이용하세요.
- 휴식 타이머의 알림음/진동은 브라우저 및 Android의 백그라운드 제한을 받을 수 있습니다.
  화면이 꺼진 상태에서도 매번 확실히 울려야 한다면 APK 버전에서 네이티브 알림 기능을 구현하는 것이 좋습니다.
